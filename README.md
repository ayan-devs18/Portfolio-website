# Aayan Qamar — Portfolio

Live: https://aayanqamar.netlify.app

- `site/` — source (Next.js 16 pages router, Tailwind CSS, Framer Motion), based on
  the codebucks27 Next.js developer portfolio starter.
- `Aayan Qamar-Portfolio/` — the static build that Netlify serves. Do not edit by hand.

All content (bio, experience, skills, projects) lives in `site/src/data/profile.js`.

To update the site:

```bash
cd site
npm install
npm run publish-site   # builds and copies out/ into "Aayan Qamar-Portfolio/"
```

Then commit both folders and push.
